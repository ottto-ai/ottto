# Claude terminal authority containment

This draft alternative withholds Claude terminal authority for every cohort.
Current-page evidence, upload, exact ACK handling and selected-index saves
continue. It has no terminal admission, staged raw effects, frozen reader or
terminal-reader allowance. The independent strict API/trace cohort has a
128-root / 16 MiB per-pass allowance, with an actual reader `take()` bound and
continuation for off-page debt. Codex and Pi retain their source policies.

The gate precedes exact removals, missing-file reconciliation, whole-absent
family retirement, tombstone draining and terminal proof folds. It also clamps
direct account/usage folds, native comparison's alternate completion route,
post-policy finalization and manifest publication. A loaded open duplicate fence
is clamped closed only in RAM for the usage fold; its persisted value is
unchanged. Incomplete or skipped member coverage cannot
verify an owned start or open the fence.

Stale-start debt does not clear settled selection fingerprints merely to
reconstruct another frozen census. Pending remains unproven. Ordinary opened
candidate validation still compares physical identity and head/tail samples;
a mismatch selects the ordinary changed-file path. Empty fingerprints and
explicit account, context, contract, history, correction and unaccepted debt
remain debt. A fresh/replayed index or destination change can continue to reselect unchanged bodies
because completion cannot adopt the new context; these selections are counted.

Existing retry admission advances one bounded root batch on resume, without
replacing the traversal for admission alone. The cursor advances over offered
roots, not just qualified carry. Real loss retains the existing retry rule.
Prior batches keep funded cancellation/replay ownership. Funding refusal retains
unproven storage debt rather than installing a partial cumulative carry.

The retained traversal re-lists metadata after restart, watcher loss and a
bounded cadence, under the existing directory/selection limits. Ordinary
candidate identity samples are counted separately from parsing. Selected saves
and local-hold restores requeue unsettled earlier-page bodies. Removals remain
withheld, so rediscovery cannot manufacture an absence manifest. Existing native
selected custody remains with the retained traversal owner.

Diagnostics include `claude_terminal_off` offers, unproven families,
`carry_admission_stalled` families and oldest age, `start_identity_sample` files
observations and bytes per walk, rediscovery, context reselection,
`owned_start_correction_deferred`, `strict_cohort_deferred` roots/bytes and
`rearm_full_suppressed`. A ctime-only change pays a second head/tail observation:
the fresh-start bound is 8 KiB per unchanged file with matching ctime, or 16 KiB
if stored ctime must be adopted. Both cases require zero body/Full bytes and
zero parses. Files and observations are counted separately. A historical
verified-but-unemitted owned start retains its correction custody without an
impossible re-arm while its strict emitter is disabled.

Small cohorts lose terminal proof recovery too: complete-family attribution and
ownership corrections, fence opening, pending retirement, context adoption,
census-proven carried-ACK/absence cleanup, complete manifests, comparison
bootstrap, replay/backfill completion and history-unverified marker clearing
remain deferred where they require completion. Accepted spend is retained;
ordinary permitted uploads still settle. Required held corrections are delayed,
potentially indefinitely during containment. No claim of eventual recovery of
expired/unavailable evidence or measured monetary equivalence is made.

Strict posture, cache and curve outputs pause on all installs (context
analytics, not money totals). Small-cohort completion corrections retain owed
custody and wait for paging: delayed, not intentionally dropped.

R1 is provided by the source-general upload-context receipt PR
(`e1/upload-context-receipt`); this draft consumes it after merge. Until then
the context-reselection control intentionally retains main's behavior. No receipt
field or per-file adoption is included here.

The paged reconstruction fold is the dependency for restoring completion.
Flipping containment alone cannot re-enable authority: the shared hard gate
also requires a same-process reconstruction certificate bound to current member
revisions, exact member coverage, and absence of outstanding holds/debt. The
current certificate supports only the conservative complete rebuild; the paged
fold must implement its bounded equivalent before authority can resume.

No persisted fields or format revision are added. Admission uses the existing
cursor; rediscovery cadence is omitted from serialization. Strict-service
continuation lives in a bounded process-owned context cache, survives ordinary
index reloads and safely starts over after a daemon restart. Tests use synthetic sources. Local validation is package clippy with
all targets; tests run in CI, never through local `cargo test`.


Completion-path regression fixtures opt in individually to a `#[cfg(test)]`
thread-scoped guard. It exercises historical completion and re-arm algorithms;
assertions in those fixtures remain unchanged. This is coverage debt the paged
fold must repay, not release evidence. Non-test builds compile a constant ON
policy and a static assertion, with no fixture override state or entry point.
A guard test checks default/thread/unwind isolation, and another checks that
money receipts, E2 money, actual finish, upload, history and correction pipelines
contain no completion override. Those pipelines exercise production containment.

#899 ships ONLY in the same release as, or after, the per-file upload-context receipt PR (e1/upload-context-receipt); never alone.

The standalone draft still fails completion-dependent end-to-end contracts;
those failures must be migrated explicitly or repaired with their owning change.
Repeated-context selection controls remain dependent on the paired receipt PR.
No passing compile or future-completion fixture is a replacement for current-head
production-default pipeline and release-cut money receipts.

- OFF is proven by main's own tests. Every main `#[test]` at the audited main
  commit is byte-identical on this branch and runs at the actual default OFF:
  the additions-only check (`#[test]` bodies keyed by module path, name and
  occurrence, comments and strings masked) reports **0 differences**. Shared
  helpers keep main's bodies; the only addition to a main helper is a
  dispatch prologue to its `terminal_off_on_*` copy, taken only under
  `ClaudeTerminalOffForTest`, never at the default OFF.
- Each main test #899 had changed now exists twice: main's exact text (OFF) and
  the #899 version as `terminal_off_on_<name>` under
  `ClaudeTerminalOffForTest::enabled()`, keeping every money/ACK/body/zero-read
  assertion. Known-red twins carry `#[ignore = "terminal-off ON-readiness:
  <cluster>"]`; a unit test pins them to `terminal_off/readiness_manifest.rs`.
- The frozen 34-case main pipeline copy is deleted: main's originals run
  instead. `terminal_off_default_off_main_tests.rs` keeps only the exact
  original-main context-fingerprint reference and the check that a shipped
  untagged main checkpoint saves/reloads/resumes with no new re-arm.
- ON→save/reload→OFF fixture requires a new traversal and retains both entries;
  ON presence/floor/hint fixtures grant no new ACK/proof.
- These are compiled controls, not runtime receipts. Linux executes them on the
  pull request; the macOS `Rust contracts` job runs only in the merge queue.
  Knob/future-paging coverage is not release proof.
- No unguarded shared money/admission/owed fix is claimed. OFF failed-open debt
  and API decoding reuse exact original main function bodies. Trace retains the
  explicitly justified shared unsafe-input refusal above (moving to its own main
  PR, t1/trace-reader-bound); cohort pacing is ON-only. ON clock fixes use
  captured audit_now; OFF preserves formerly fresh clock calls.
- Fixed RAM fields are skipped in serialization and honestly heap-accounted;
  no claim of identical struct addresses/RSS is made. Entry layout stays 560B.

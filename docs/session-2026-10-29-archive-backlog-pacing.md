# Archive backlog pacing and classification

Codex discovery recognizes exact `.jsonl.zst` paths. Other sources retain their
plain `.jsonl` filters. Physical paths remain index and acknowledgement keys;
logical locator comparisons strip only the archive suffix.

Selected pages order live files before archive work, then order archives newest
first. Preparation bounds inspected roster entries before filtering. A partial
header inventory cannot certify owner absence. RAM scheduling state carries CPU
and accumulated work through continuation pages and partial commits; archive
admission shares continuation's contention threshold. Unknown power denies work.

Resolved archive families are held while plain members keep their existing
publication behavior. Moves retain old evidence; oversized catch-up is held
before decoding. A funded first read has a 1 GiB decoded limit in addition to the
independent decoder ceiling. Held evidence never supplies an acknowledgement.

Owner-wide custody is paged before cached inventory filtering and checked again
before retained-cache takes. Omitted archives retain negative absence scope.
Upstream cache/retention composition and runtime qualification remain release gates.
Native power uses the continuation platform seam. Pending archive resends use
retained reductions; synthetic fixtures are present but unexecuted.

Completed archive reductions may enter the existing process cache under its
normal accounting and admission rules. An unchanged pending archive can resend
that reduction through native finalization and exact body ACK settlement without
creating a decoder. `codex_zst_retained_resend` counts these hits. Losing the
retained copy still permits the existing paced, bounded
`codex_zst_first_read_retry` exception, including admission-refused copies.
The in-process retry consumes 0 decode bytes; re-decode after restart/eviction
remains a named bounded exception; exit = P5 candidate: durable archive restore
(needs SOURCE representation). Archives remain replace-only and excluded from
durable restoration and post-save durable writes.
The cache's archive witness grants no physical prefix or side-ledger seal.

Queued archive scheduling metadata is RAM-only and charged with its existing
queue owner. Within the complete header-inventory population it orders archives
newest first before page selection, preserves plain FIFO, and reuses the metadata
on later pages. The preparation bound stays at the existing header population;
an oversized population keeps the existing inventory/custody limitations.

Archive checkpoints carry a heap-accounted RAM domain marker. Only pending
archive re-emission can take them; plain acquisition and physical-prefix plans
reject them. Header-bound evidence is valid only for the same content/object
stamp. Missing or malformed flags load false, allowing at most one bounded
64 KiB header decode; older decoders drop the evidence.

Downgrading below the archive-activation release is unsupported. Older binaries
ignore archive evidence and may retire accepted archive entries. A re-upgrade may
therefore read each such archive once more as a paced A1. `archive_reupgrade_full`
counts actual first reads with an exact semantic fingerprint in accepted history;
retained resends never increment it. It does not reconstruct missing history.
Whole-session bodies use latest-wins replacement. Protection against downgraded
state-only output depends on the deployed backend authority fence; code inspection
does not establish deployment. Accepted bodies without the exclusive contract or
positive attributed usage have no such protection.

# Codex archive intake v1

Codex discovery and watcher hints include exact `.jsonl.zst` suffixes by default.
Claude and Pi retain their existing readers. All sources retain the ordinary
parser, reducer, line delivery, upload policy and destination receipt owners.

An archive can publish only when its own header names a standalone native
session. Every configured root and relevant home must have complete absence
coverage through the existing census owner. Any plain or archive claimant of
the same session is held before Full decoding. Unknown or damaged headers,
unresolved parents and conflicting creators are also held. V1 does not use
response signatures, cumulative totals or accepted plain bodies to establish
archive domination or replacement.

Archive debt blocks only archive-dependent decisions. It is counted and alarmed
separately from ordinary unreadable-file errors. Unaccepted reservations remain
owed after a crash. The existing disclosed-loss receipt channel reports money
as incomplete without lowering the source census flag: ordinary backfill/replay,
plain re-offers, manifest and acknowledgement retirement keep their native gates.
No unknown usage becomes a zero total.

The bounded header prefix is inventory work, separate from a Full read. Header
attempt markers are saved as a batch before decoding; incomplete attempts after
a restart wait for their saved six-hour retry. One batch saves all admitted Full
reservations for the page before any Full body bytes. Decoder allocation is prepaid through the
existing shared cache. The same native parser continues in RAM across decoded
pages to EOF; a process restart loses that checkpoint.

Power, CPU, contention and byte-budget refusal before a Full remain eligible on
the next pass. A spent Full keeps its saved six-hour retry deadline. An unchanged
structural cause does not trigger another Full. Parent support and same-session
union bodies are follow-up work. The archive CPU/work allowance gates admission
of the next archive; a started Full retains its RAM parser to EOF. Unconsumed
reservations cancel without a Full penalty. Power is sampled once per page.
Caps retain owed discovery and disclose refusal.

Exact accepted body witnesses in the current destination settle an archive.
Settled archive markers keep only object stamp and disposition; acquisition
headers and body scratch are discarded. Settled files use listing stamps rather
than repeated opens or one scan step per archive. Only immutable inventory coverage
is shared. Live scope checks run for each archive at admission and publication,
validating each directory home once within a check. Archive work restores the native continuation QoS when it finishes.
Archive state uses the existing index save and state-store owners, with no slot added to ordinary file entries.

Release note: context or replay changes retain accepted archive money and mark
`CorrectionUnapplied` once per transition. No automatic archive reread is granted;
generic correction/evidence debt remains a named follow-up.

Other follow-ups are same-session union bodies, retained resend, durable
continuation if measurement justifies it, archive parents, shared listing/owed
resolution, placement-comparator convergence and resource measurements. The
historical-writer compatibility probe currently runs in Linux CI; running it only
at release cuts is follow-up work.

Header and Full reservation batches currently require up to two committed index
saves per pass. Held counts aggregate by cause; generic alarms occur on transitions.
Malformed archive records become archive debt without ordinary decode holds.

Archive refusals use one transition owner. Quiet outcomes preserve their marker;
unspent transient or correctness refusals cancel their reservation; spent refusals
retain the saved retry deadline; structural byte failures and correction debt stay
quiet on the same stamp. Pending stores its attempt/deadline only in boxed work.
Known missing archives retire their markers. Unknown collection metadata has one
named, non-path debt marker; typed records are checked on load.

A started Full retains the native RAM parser across decoded-byte pages and runs
to EOF. Work/CPU allowances gate the next admission, never discard a started
parser. Live content, archive and directory witnesses are rechecked for each
archive at admission and publication; only immutable coverage is memoized.
One damaged or unknown header defers every archive uniqueness proof. Resource
receipt refusals can recur at the six-hour pace. Process memory measurement is owed.

Transitions guard settled, correction, decoded structural and receipt-waiting
states. Correction retains the ordinary file owner without creating header-less
work. Receipt-waiting Pending is quiet only with its exact file incidence and
before the saved deadline; an unaccepted expired body takes a paced native retry.
Partial checkpoints retain the previous marker outside accepted safe keys, and
reservation saves copy only their own new reservations. Header-less Reserve and
marker creation by correctness/structural refusal are refused by the owner.
